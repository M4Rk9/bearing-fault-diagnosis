# 2026-11-26 — Hybrid CNN–LSTM experiment

We extended the original STFT/DWT CNN into a parallel hybrid with an LSTM branch for Envelope sequences. [PR #9](https://github.com/M4Rk9/bearing-fault-diagnosis/pull/9) integrated the aligned inputs; [PR #10](https://github.com/M4Rk9/bearing-fault-diagnosis/pull/10) added the experiment runner, Jupyter notebook, baseline comparison and report generation.

## Execution

The initial Windows run encountered Application Control restrictions on TensorFlow and Jupyter. After the local environment became operational, the notebook first failed to locate the ZIP and then rejected the unsplit archive structure. We switched to the extracted numerical dataset with train_70 and test_30 directories. The team ran dataset validation, training and report generation in Jupyter. TensorFlow 2.21.0, seed 42.

## Measured outcomes

| Metric | Baseline | Hybrid |
|---|---:|---:|
| Clean window accuracy | 97.87% | 100.00% |
| Noisy window accuracy | 94.29% | 96.70% |
| Noisy macro-F1 | 0.9400 | 0.9657 |
| Noisy recording accuracy | 9/10 | 10/10 |

The hybrid ran 15 epochs (best epoch 10), baseline 16 (best epoch 12). The hybrid reduced noisy errors from 83 to 48, all remaining errors being Inner Race predicted as Outer Race. The saved run reports 20/10/10 recording groups across train/validation/test.
